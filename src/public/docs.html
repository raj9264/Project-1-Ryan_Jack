Countries API Project
Documentation

Browse country data or add and edit countries using these endpoints.

Changes are temporary, and reset when the server is restarted.

Request example

GET /api/countries?region=Europe&limit=5 
fetch('/api/countries?region=Europe&limit=5', {
  headers: { Accept: 'application/json' }
})
  .then(response => response.json())
  .then(data => console.log(data));

GET and HEAD

GET / HEAD /api/countries

Returns all countries, with optional filters.

Optional query parameters:

  • name - match part of a country name
  • region - filter by region
  • subregion - filter by subregion
  • currency - filter by currency code
  • limit - maximum results (positive integer)

Responses: 200 country array; 400 invalid limit.

Example: /api/countries?region=Europe&limit=5

GET / HEAD /api/regions

Returns an array of unique region names

Response: 200 JSON array

Example: /api/regions

GET / HEAD /api/countries/:name

Returns one country. The name path parameter is case-insensitive; URL-encode spaces and special characters.

Responses: 200 country object; 404 country not found

Example: /api/countries/Switzerland

GET / HEAD /api/countries/:name/timezones

Returns the selected country's time zones. The name path parameter identifies the country.

Responses: 200 time-zone array; 404 country not found.

Example: /api/countries/Switzerland/timezones

POST

Send a request body as JSON or application/x-www-form-urlencoded.

POST /api/countries

Adds a country. Required fields:

  • name - unique country name
  • capital - capital city
  • region and subregion
  • finance.currency - currency code

Other country fields are optional.

JSON body 
{
  "name": "Example Land",
  "capital": "New Example City",
  "region": "Europe",
  "subregion": "Northern Europe",
  "finance": { "currency": "EXM" }
}

Responses: 201 created; 400 invalid or duplicate country; 415 unsupported content type.

POST /api/countries/:name

Updates an existing country. The required name path parameter is its current name. Include only the fields to change.

JSON body example 
{
  "capital": "New City",
  "finance": { "currency": "NEX" }
}

Responses: 204 updated; 400 invalid request; 404 country not found; 415 unsupported content type.

RESPONSE DETAILS

Status codes

  • 200 OK - Request succeeded.
  • 201 Created - Country added.
  • 204 No Content - Country updated; no response body.
  • 400 Bad Request - Invalid request or data.
  • 404 Not Found - Endpoint or country not found.
  • 415 Unsupported Media Type - Unsupported POST body format.

Data responses are JSON. GET and HEAD do not change data. Added and edited countries are stored in memory only.
